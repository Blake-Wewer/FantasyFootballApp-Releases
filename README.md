# Installing Fantasy Football App
## Windows
    1. Download FantasyFootballApp.MAUI-win-Setup.exe.
    2. Double-click it. If Windows shows "Windows protected your PC", click More info → Run anyway.
    3. The app installs and opens automatically. No admin rights needed.
## Mac
    1. Download the Mac installer and double-click it.
    2. macOS will block it the first time. Open System Settings → Privacy & Security, scroll down, click Open Anyway, and confirm.
    3. If Open Anyway doesn't appear, open Terminal and run
            xattr -d com.apple.quarantine ~/Downloads/<installer file name>
        then double-click the installer again.

Updates: after the first install, the app checks for new versions each time it starts and updates itself. You never need to download it again.
